# FireBot — chi tiết in 3D đợt 2
File nguồn: firebot_parts2.scad (dùng chung tham số với firebot.scad).
Xuất 1 chi tiết: openscad -D 'p="link1"' -o link1.stl firebot_parts2.scad
Nắp có chữ nổi: -D 'p="call_lid"' -D 'id=2'  ·  -D 'p="module_lid"' -D 'id=5'
Danh sách, số lượng, kích thước, khối lượng: xem FireBot_chi_tiet_in_3D.pdf.
Đo servo / bát servo / cảm biến thật, sửa tham số ở đầu file trước khi in.
